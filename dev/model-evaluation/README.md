# Model evaluation fixtures

This opt-in fixture uses a fixed fictional payment catalogue with the packaged public SDK. Its inference, abstention and hostile-document checks are experiments, not a model recommendation or automatic migration approval.

Setup, pinned 1.5B/7B profiles, the explicit Codex synthetic JS/Python/Java catalogues, bounded execution, separate semantic review and evidence limits are maintained in the [canonical technical guide](../../docs/technical-guide.pdf#page=15). Profile bytes and licenses remain in profile.mjs. Outputs and weights stay under ignored work/.
