# Python and Java acceptance fixture

This opt-in Linux fixture uses fictional payment contracts over real loopback sockets. The installed SDK captures explicit Python/Java source, preserves read-only tests and validates operator-reviewed recipes through separately approved isolated jobs. Candidates are manually authored; this fixture does not establish real AI migration quality or automatic call discovery.

Prerequisites, pinned Python and Java 25 images, commands, retained evidence and discovery limits are maintained in the [canonical technical guide](../../docs/technical-guide.pdf#page=16). Outputs belong to a fresh directory outside this checkout; no private account or payment service is used.
