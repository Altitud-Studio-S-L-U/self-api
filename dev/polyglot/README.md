Prerequisites, pinned Temurin image, commands, retained evidence and the JS/TS product boundary are maintained in the [canonical technical guide](../../docs/technical-guide.pdf#page=16). Outputs belong to a fresh directory outside this checkout; no private account or payment service is used.
