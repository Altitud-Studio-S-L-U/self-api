# Terminal replay fixture

This opt-in recorder uses fictional payments, local contracts and the reviewed payments recipe through the public SDK. GitHub publication transport is simulated; it does not open a real pull request or describe real customer statistics.

Runtime prerequisites, recording commands, approval boundaries and replay review are maintained in the [canonical technical guide](../../docs/technical-guide.pdf#page=16). Private execution receipts stay under ignored work/terminal-demo; only the reviewed public-replay.json may be copied to Cloud.
